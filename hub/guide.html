Workbench · the rig

Set up the rig

Everything runs at home on the rig, the computer that stays on: the AI (Ollama), the Workbench Hub and your files. Your other devices reach it through Tailscale, at home or away. Tick each step as you go. Your ticks are remembered on this device.

A Prepare the rig

About 10 minutes. Do this with the monitor plugged in.

  1. Update Windows. Start → Settings → Windows Update → Check for updates. Install everything and restart if it asks. Repeat until it says you're up to date.
  2. Update the graphics driver. Open the NVIDIA App (or GeForce Experience) → Drivers → install the latest Game Ready driver. If you have neither, get the driver from nvidia.com/drivers: pick GeForce, your card's series and model, and Windows 10/11. The AI needs a recent driver to use the graphics card.
  3. Let it sign back in after updates. Settings → Accounts → Sign-in options → turn on Use my sign-in info to automatically finish setting up after an update. The Hub starts when Windows signs in, so this keeps it running after update restarts.
  4. Never sleep. Settings → System → Power & battery → Screen and sleep → set When plugged in, put my device to sleep after to Never. The screen can still turn off; that's fine. (The Hub installer sets this too.)
  5. Optional: come back on after a power cut. When the rig starts, press Del or F2 to open the BIOS → Advanced → APM Configuration → Restore AC Power Loss → Power On → save and exit (F10). Menu names vary a little between boards.

B Tailscale on the rig

Tailscale links your own devices privately, so your phone and laptop can reach the rig from anywhere. Nothing is opened to the internet. It's free.

  1. On the rig, go to tailscale.com/download → Download for Windows → run the installer → Install.
  2. The Tailscale icon appears in the tray (bottom right, near the clock; click ^ if you don't see it). Click it → Log in. Sign in with the account you'll use everywhere, for example Google. Use this same account on every device.
  3. Give the rig a short name. In a browser open login.tailscale.com/admin/machines → find the rig → ⋯ → Edit machine name → type rig → Update. Your address will then start with rig.
  4. Turn on secure addresses. Open login.tailscale.com/admin/dns. Make sure MagicDNS is on, then scroll to HTTPS Certificates → Enable HTTPS → confirm. The installable app needs this https address.

C Install the Hub and the AI

One installer does it all: the Hub, starting with Windows, the tray icon, the AI (Ollama) and its model. About 15 minutes, mostly downloading.

  1. On the rig, open tonystarkofficial1111-web.github.io/Workbench/hub/WorkbenchHub.zip. It downloads to your Downloads folder.
  2. Open Downloads → right-click WorkbenchHub.zip → Extract All… → Extract. A folder opens with the Hub's files.
  3. Open the WorkbenchHub folder and double-click Install Workbench Hub. If a blue box says Windows protected your PC, click More info, then Run anyway. A black window opens and asks a few questions; type the answer and press Enter each time.
  4. 1/7 Node.js downloads by itself (about 30 MB). Nothing to answer.
  5. 3/7 Where to keep everything: it lists your drives and how much space each has, and suggests a folder. Press Enter to accept it, or type one like D:\Workbench Hub. This folder will hold Work, design files, everyone's own music and videos, and saves.
  6. Your big folder: it then asks for your own big folder of everything. Type its full path, like D:\My Stuff, and press Enter. You can also press Enter to skip and add it later (part E). To copy a folder's path: open it in File Explorer, click the address bar at the top, and copy what's there. Paste into the black window with a right-click.
  7. 4/7 You, the owner: type your name, then a PIN of 4 to 12 digits, twice. Nothing shows while you type the PIN; that's normal. You'll sign in with this name and PIN on every device.
  8. 5/7 Start with Windows: done for you. The Hub now starts by itself.
  9. 6/7 Tailscale: it shares the Hub on your tailnet. If Tailscale shows a link saying HTTPS or Serve isn't enabled, open that link, press Enable, and the installer continues by itself. Then it shows Your Hub's address, like https://rig.tail1234.ts.net, and copies it. Write this address down; you'll type it on your other devices.
  10. 7/7 The AI: it asks Install Ollama now…? (Y/N). Type Y → Enter. Ollama downloads (about 1 GB) and installs by itself; a llama icon appears in the tray. Next it asks Download the AI model llama3.1:8b…? (Y/N). Type Y → Enter. This is about 5 GB, so give it a while; you'll see a progress bar. It fits a graphics card with 8 GB.
  11. At the end it says THE HUB IS RUNNING, with your folder and address. Press any key to close the window. You'll see the Workbench Hub icon in the tray. Hover over it and it should say Workbench Hub - Online.
You don't need the OLLAMA_ORIGINS or OLLAMA_HOST settings on the rig. The Hub talks to the AI on the rig itself and hands it to your devices, so leave those unset there.

D Check the AI works on the graphics card

  1. Press Start, type PowerShell, open Windows PowerShell.
  2. Type this and press Enter:
    ollama run llama3.1:8b
    Wait for >>>, which takes 10 to 30 seconds the first time. Type Say hi in Spanish → Enter. It answers.
  3. Type /bye → Enter. Then type this and press Enter:
    ollama ps
    Under PROCESSOR it should say 100% GPU, which means it's using the graphics card. If it says CPU, update the NVIDIA driver (part A, step 2) and restart the rig.
  4. If the installer couldn't install Ollama: go to ollama.com/download → Download for Windows → run OllamaSetup.exe → Install. Then in PowerShell run ollama pull llama3.1:8b and do steps 2 and 3 again.

E Your big folder

Put everything in one folder on the rig, however you like. Workbench reads it where it is: nothing is moved or copied, and new files show up by themselves.

What it findsHow
MusicAudio files (MP3, M4A, FLAC, WAV…) in folders named like Music, Songs, Audio, Beats, DJ, Música, plus any audio file that's clearly a song (over ~1 MB) anywhere else.
VideosVideo files (MP4, MOV, MKV, WEBM…) over 1 MB, for example in Videos, Movies, Clips.
Left aloneFolders named like Photos, Pictures, Camera, Camera Roll, DCIM, Screenshots are skipped completely, even videos inside them. So are program folders and tiny sound effects. Photos and documents aren't picked up.
  1. Tip: name the folders that hold your music Music (or Songs, DJ…) and your videos Videos (or Movies…). Any layout inside them works.
  2. If you skipped it in the installer, add it later from any device once you're signed in (part F): the bell → Hub → Folders on the rig → Add a folder…. Click through the rig's drives to your folder → Use this folder. Tick Family can see it too only if it's for everyone.
  3. After a minute it shows how many songs and videos it found. They're in Media → Rig library and in Work → DJ → Library → Rig library.

F The laptop

  1. Install Tailscale on the laptop (tailscale.com/download) and log in with the same account as the rig.
  2. Open Workbench → the bell at the top right → Connect the Hub. Type the address from part C (like https://rig.tail1234.ts.net), your name and PIN → Connect. If the browser asks to let the site reach devices on your network, choose Allow. Your Work goes up to the rig. The laptop's Work folder and its design files are copied up too.
  3. In the same window: AI → Use the rig's AI here. It should say this device now uses the AI on the rig.
  4. Try it: Work → the round chat button at the bottom right → ask What should I do today?
  5. Remove Ollama from the laptop (it's not needed there any more): Settings → Apps → Installed apps → Ollama → ⋯ → Uninstall. Then open File Explorer, go to C:\Users\<your name>, and delete the .ollama folder (that's several GB of models). Also delete the two settings from before: Start → type environment variables → Edit environment variables for your account → select OLLAMA_ORIGINS → Delete, and the same for OLLAMA_HOST → OK.

G The phone

  1. Install Tailscale from the Play Store, open it, log in with the same account and turn it on. Android asks to set up a VPN connection; press OK.
  2. Open the Workbench app → bell → Connect the Hub → address, name, PIN → Connect. Work comes over; open it with your Work PIN as usual.
  3. Notifications on this device → Turn on → Allow. Then press Send a test; a notification should arrive within a few seconds. If it doesn't, check Android Settings → Apps → Workbench → Notifications is on, and Battery is set to Unrestricted.
  4. AI → Use the rig's AI here.

H Unplug the monitor

  1. Leave the rig on and unplug the monitor. Everything keeps running.
  2. From your phone, the bell's small dot shows the rig: green = online. In the bell → Hub you'll see Online · rig.
  3. Family: in the Hub window, under People, add each person with their own PIN. On their device they install Tailscale (signed into your account, or you share the rig with their own account: Tailscale admin → Machines → rig → ⋯ → Share), then sign in to the Hub with their name and PIN.
That's it. The Hub updates itself from the Workbench site, keeps a daily copy of your Work data (90 days, in the Hub folder's hidden .hub\backups), and writes the AI's hourly summary on the graphics card.

If something's wrong

What you seeWhat to do
"Can't reach the Hub"Is Tailscale on, on this device? Is the rig on? On the rig, hover the Hub's tray icon: it should say Online. If not, right-click it → Restart the Hub.
No Tailscale address shown at the end of the installerDo part B, steps 2 to 4, then double-click Install Workbench Hub again. Running it again is safe and keeps your data.
"The AI isn't running on the rig"On the rig, start Ollama from the Start menu (it then starts with Windows). Check with part D.
Forgot your PINOn the rig, in the WorkbenchHub folder you extracted, double-click reset-pin.bat, type your name and a new PIN.
Something odd happenedOn the rig: right-click the Hub's tray icon → Show the log, and send me a photo of the last lines.
